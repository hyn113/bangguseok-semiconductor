# 건식/습식 산화 · 웹용 GLB 에셋 v2

이 패키지는 기존 Blender 원본을 웹에서 사용하기 위해 변환한 파일입니다. 웹 페이지나 배포된 서비스가 아닙니다. 건식(dry)과 습식(wet)을 별도 파일로 나눴습니다.

## 단계별 파일
각 공정은 동일한 5단계 파일로 구성됩니다.
1. `*_01_prepare.glb`: 준비 상태. 정적 모델, 애니메이션 없음.
2. `*_02_load.glb`: 보트/웨이퍼 투입. 약1.97초의 1개 합쳐진 애니메이션 클립.
3. `*_03_oxidize.glb`: 산화 처리 위치. 3초의 가스 방향 표식 움직임. 기체 유동이나 실제 산화막 계산이 아닙니다.
4. `*_04_unload.glb`: 완료/냉각 후 반출 개념. 1초의 보트/웨이퍼 반출 클립. 실제 냉각 절차 생략.
5. `*_05_growth_detail.glb`: 해당 공정의 확대 단면. 약4.96초의 산화막 성장/실리콘 소모 개념 애니메이션.
클립 시작 시간은 모두 0초로 이동해 앞의 불필요한 정지 시간을 제거했습니다. 반복 대신 1회 재생 후 마지막 프레임 유지가 자연스럽습니다. 속도는 웹에서 조절할 수 있으며 위 길이는 실제 공정 시간이 아닙니다.

## 구현 시 유의
- 각 GLB는 활성 장면 하나만 포함하며 다른 단계 장면이 중복 들어 있지 않습니다.
- 조명, 카메라, 큰 바닥 평면은 제외했습니다. 앱에서 카메라와 환경광/스튜디오 조명 또는 HDR 환경을 제공해야 합니다. 빛 없이 어둡게 보이는 것은 모델 누락이 아닙니다.
- Blender의 곡선·텍스트를 메시로 변환하고 Bevel/Weighted Normals 등 모디파이어를 적용했습니다.
- 표준 metal/rough PBR 재질 및 석영용 KHR_materials_transmission, KHR_materials_ior를 사용합니다. 지원하는 GLTFLoader/렌더러에서 로드하세요. 환경광/톤 매핑 차이 때문에 Blender 렌더와 동일하게 보이지 않을 수 있습니다.
- 파일별 약3.1MB, 건식 설비 약8.4만 삼각형/150메시, 습식 약8.6만 삼각형/151메시. 모바일용 LOD·메시 병합·압축은 하지 않았습니다. 모든 단계를 동시에 로드하기보다 필요한 단계만 로드하세요.
- 재질 텍스처/외부 이미지 의존성 없음. 모든 형상·색이 GLB 안에 있습니다.
- Blender 원본에서 직접 편집하는 기능은 GLB보다 제한됩니다. 편집은 전달한 .blend 원본을 권장합니다.

## 검증
- 10개 파일 모두 GLB 길이, 단일 장면, 유효한 메시 좌표, 비어 있지 않은 경계, 카메라/조명 제외 확인.
- 실제 Three.js GLTFLoader로 10개 모두 파싱 성공.
- AnimationMixer로 준비 장면 이외의 8개 파일 모두 클립 시작/끝 변환 변화 확인.
- 1개 습식 산화 GLB를 Blender로 재수입하여 렌더로 형상·재질의 기본 유지 확인.
- 실제 브라우저 GPU 렌더링, Mac/Safari, 모바일 성능 테스트는 미실시. Three.js 파싱 테스트는 브라우저 화질/성능 검증과 다릅니다.
- 기존 사이트에 적용하거나 배포하지 않았습니다.
