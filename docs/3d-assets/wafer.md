# 방구석 반도체 · 웨이퍼 제조 3D 학습 에셋 v1

## 구성
- `wafer_manufacturing.blend`: Blender 4.3.2 원본, 공정별 6개 Scene.
- `01_01_CZ_growth.glb`: 종자 결정과 CZ 단결정 성장. 프레임 1–120 애니메이션.
- `02_02_as_grown_ingot.glb`: 참고 사진의 길쭉한 몸통, 목과 어깨를 반영한 성장 직후 잉곳.
- `03_03_crop_and_grind.glb`: 어깨/꼬리 제거를 분리 애니메이션으로 설명. 외경 연삭 장비와 연삭 운동 자체는 미구현.
- `04_04_wire_slicing.glb`: 가공된 잉곳에서 원판으로 분리되는 과정. 와이어는 개념 표시.
- `05_05_polishing_comparison.glb`: 절단면과 연마면의 거칠기 비교. 연마 장비 운동 자체는 미구현.
- `06_06_finished_blank_wafer.glb`: 회로 없는 웨이퍼와 방향 식별용 노치.
- PNG: Blender 실제 렌더. `build_wafer.py`: 재생성 가능한 제작 스크립트.

## 보는 법
Blender에서 원본을 열고 상단 Scene 메뉴에서 01~06을 선택하세요.
성장/절단/끝단 분리 장면은 타임라인 1~120 프레임을 재생하면 됩니다.
웹에서는 각 GLB를 따로 로드하고 AnimationMixer에서 클립을 재생할 수 있습니다.
GLB에는 모델과 기본 PBR 재질을 담았으며, Blender 스튜디오 조명과 바닥은 제외했습니다.
웹 뷰어는 별도 환경 조명/HDR을 설정해야 반사가 보입니다.
기존 서비스 코드와 배포 사이트는 변경하지 않았습니다.

## 범위와 한계
교육용 개념 모델이며 제조 장비 설계도나 공정 물리 시뮬레이션이 아닙니다.
사진 한 장으로 실측 복원한 스캔 모델이 아니라 형태 특징을 참고하여 새로 제작했습니다.
공정 시간, 원판 두께/간격, 표면 거칠기를 인지하기 쉽게 과장했습니다. 단위는 임의입니다.
성장 애니메이션은 설명용 스케일 변화로, 결정화/용융액 수위/열전달/결정 결함을 계산하지 않습니다.
절단 과정의 재료 손실(kerf), 실제 다중 와이어 구조, 냉각수, 내부 손상층은 모델링하지 않았습니다.
실제 제조의 외경 연삭·가장자리 가공·래핑·식각·폴리싱·세정·검사 중 일부는 설명으로만 다룹니다.
완성 웨이퍼에는 회로나 다이 격자를 넣지 않았습니다. 그것은 후속 소자 제조 단계입니다.
Blender 절차적 미세 성장 무늬 셰이더는 GLB로 그대로 변환되지 않으며 기본 재질로 근사됩니다.
