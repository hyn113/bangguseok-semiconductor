# bangguseok-semiconductor
신홍탄 팀 | 방구석 반도체

반도체 입문자를 위한 React · TypeScript · Three.js 기반 학습 웹앱입니다.
2026-11-12의 v23 사이트 작업본을 팀 공동 개발용으로 옮겼습니다.

## 시작하기

Node.js 22 LTS와 npm을 사용합니다.

```sh
npm ci
npm run dev
```

개발 서버: http://127.0.0.1:5173

```sh
npm test
npm run build
npm run preview
```

`npm run build`는 TypeScript 검사와 Vite 빌드를 실행합니다. 정적 배포 파일은 `dist/`에 생성됩니다.
`npm test`는 DOM 기반 회귀 테스트입니다. 실제 GPU 렌더링이나 휴대폰 터치 검증을 대신하지 않습니다.
선택적인 `npm run test:browser`는 별도의 Chromium 설치와 미리보기 서버가 필요하며 환경에 맞는 `CHROMIUM_PATH`, `BASE_URL` 설정 및 화면 경로 점검이 필요합니다.

## 주요 기능

- 선택형 클린룸 소개와 착의 입문 체험
- FFU 구성 요소, 공기 흐름, 메모와 개념 확인
- 잉곳에서 웨이퍼로 이어지는 기초 학습
- MOSFET 구조, 전압·W/L 조절, 전류 그래프와 퀴즈
- 포토공정: PR 도포 → 소프트베이크 개념 → 마스크·노광 → 현상·린스·건조 → 결과와 퀴즈
- 전체 / 8대공정 / 장비 / 설계 탭과 좌우 학습 카드 선택
- 포토공정·MOSFET의 설명/조작, 중앙 모형, 메모/AI 안내 패널

## 콘텐츠 범위와 저장

이 앱은 전문가 검수 전의 교육용 시제품입니다. 실제 장비 운전, 공정 레시피, 현장 안전 절차, 시설별 SOP를 대체하지 않습니다.
포토공정은 양성 포토레지스트의 개념을 보여주는 2D 단면 체험이며 실제 공정 조건·선폭·수율 계산이 아닙니다.
MOSFET은 이상적인 교육 모델입니다. 3D가 지원되지 않는 환경에는 일부 대체 화면이 제공됩니다.

별도 백엔드·API 키 없이 실행할 수 있습니다. AI 어시스턴트는 미연결 상태입니다.
일부 메모와 학습 기록은 현재 브라우저의 localStorage에만 저장되며 기기 간 동기화되지 않습니다.
포토공정과 MOSFET의 진행·퀴즈 상태는 현재 세션에만 유지됩니다.

## 팀 협업 / Codex

이 저장소를 개발 기준으로 사용하세요. 새 작업은 별도 브랜치에서 진행하고 변경 내용을 검토한 뒤 합치는 것을 권장합니다.
Codex에서 이 저장소를 선택하거나 복제한 작업 환경을 사용하고, 설치 명령은 `npm ci`, 검증 명령은 `npm test && npm run build`로 지정할 수 있습니다.
저장소 선택이나 Codex 환경 설정이 자동으로 완료된 것은 아닙니다.

GitHub에 코드를 반영하는 것과 기존 사이트에 배포하는 것은 별개입니다. 이 저장소에는 자동 배포 연결이나 워크플로가 설정되어 있지 않습니다.
기존 Sites 전용 호스팅 식별 설정은 이 저장소에 포함하지 않았습니다.

API 키, 비밀번호, `.env` 파일, 개인 학습 기록을 커밋하지 마세요. 사용자 정보나 실제 성과를 가정한 예시도 넣지 마세요.

## 디자인 시스템

- 토큰: `src/tokens.css` — 색, 글자 크기 6단계(36/20/16/14/13/12), 간격(모두 4px 배수), 모서리, 그림자
- 아이콘: [Bootstrap Icons](https://icons.getbootstrap.com) — `src/Icon.tsx`에 쓰는 아이콘만 경로로 들어 있어요. 새 아이콘은 같은 형식으로 추가하세요.
- 학습 화면 셸: `src/LessonShell.tsx`, `src/lesson-shell.css` — 떠 있는 좌우 패널(접기/펼치기, `Ctrl/⌘ + \`), 가운데 캔버스, 하단 도구 막대(둘러보기 · 조절)
- 메모: `src/NoteSheet.tsx` — 입력하는 즉시 이 브라우저에 저장돼요.
- 블렌더 3D 모형: `.glb`로 내보내 `public/models/`에 넣고 `src/lessonModels.ts`에 등록하면 그 화면의 가운데 캔버스가 기본 모형 대신 그 파일을 보여 줘요. 내보내기 설정과 분해하기 규칙은 파일 맨 위 주석에 있어요. 조절 패널은 분해하기 · 초기화 · 보기(좌우 패널 닫기)예요.
- 구성 요소 이미지·영상: `src/lessonMedia.tsx`에 경로를 등록하면 왼쪽 패널에 나타나고, 등록하지 않으면 보이지 않아요. 파일은 `public/media/`에 넣으세요.

## 구조

- `src/`: 화면, 학습 로직, 3D 모형과 스타일
- `public/`: 화면에 사용하는 이미지
- `tests/`: DOM 및 선택적 브라우저 테스트
- `package-lock.json`: 재현 가능한 의존성 설치
