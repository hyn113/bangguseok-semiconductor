# RIE 식각기 단계별 웹용 GLB

## 구성
1. `rie_01_overview.glb` 외관/절개 챔버 (정적)
2. `rie_02_exploded_parts.glb` 부품 분해
3. `rie_03_wafer_load.glb` 웨이퍼 투입
4. `rie_04_evacuation.glb` 배기 경로 (정적 화살표)
5. `rie_05_gas_supply.glb` 공급 가스 방향 표식
6. `rie_06_plasma_etch.glb` 플라즈마 개념 표식
7. `rie_07_end_unload.glb` 종료 후 웨이퍼 반출
8. `rie_08_masked_etch_magnified.glb` 보호막/대상막/기판 확대 단면

애니메이션은 약 3.97초의 교육용 움직임이며 실제 공정 시간이 아닙니다. 각 파일은 독립 장면이고 클립은 0초부터 시작합니다. 분해·투입·반출은 반복하지 않고 한 번 재생한 뒤 끝 상태를 유지하는 구성이 적합합니다. 초기화할 때는 애니메이션 시간을 0으로 돌리세요.

## 웹에서 사용
Three.js GLTFLoader 등으로 GLB를 불러오고 AnimationMixer에 포함 클립을 연결할 수 있습니다. GLB 자체에는 버튼·한글 설명 UI·퀴즈가 포함되지 않습니다. 선택한 단계만 로드하고 카메라 위치를 모델 범위에 맞춰 잡으세요.
색·금속성·거칠기가 포함되어 있습니다. 카메라·조명·스튜디오 바닥은 제외했으므로 웹에 환경광/조명을 설정해야 합니다. Blender 원본과 웹 뷰어의 색관리·노출·조명 차이로 보이는 색과 반사가 달라질 수 있습니다.

## 검증 범위
- 8개 파일 모두 Three.js GLTFLoader로 파싱 확인
- 단일 장면, 메시 좌표, 비어 있지 않은 범위, 필요한 장비 부품과 재질 확인
- AnimationMixer로 6개 클립의 시작/끝 변화 확인
- 웨이퍼 투입/반출 초기·끝 위치 및 마스크 동반 이동 확인
- 확대 단면 노출 대상막의 축소 확인
- 투입 완료 및 단면 GLB를 Blender로 다시 가져와 렌더 확인
- 실제 Mac/Safari/모바일 브라우저 GPU 화면이나 성능은 검증하지 않았습니다.

## 제한
교육용 초안입니다. 챔버 절개와 색·입자·화살표는 관찰을 위한 표시이며 실물 사진급 완성 모델, CFD/화학/전기장 시뮬레이션, 실제 장비 운전 안내가 아닙니다. 실제 공정 중 챔버는 밀폐되어 있습니다. 퍼지·벤트·냉각과 안전 인터록은 구현하지 않았습니다. 단계 전환·조작 UI는 별도로 구현해야 합니다.

장비 장면 약 5.2~5.9만 삼각형과 93~155개 메시, 확대 단면 약 1.5만 삼각형입니다. 모바일 LOD·메시 병합·Draco 압축은 적용하지 않았습니다. 공정 장면 여러 개를 한꺼번에 로드하면 비용이 커질 수 있습니다.

## 제작·권리·참고
Blender 기본 형상과 자체 작성 스크립트로 만든 일반적인 RIE 교육용 모델입니다. 외부 3D 모델·사진·텍스처를 삽입하지 않았고 로고/상표도 넣지 않았습니다. 특정 제조사의 CAD·실제 치수·고유 외관을 재현한 모델이 아닙니다. 사용자 사진은 금속 교육 모형의 분위기 참고에 한정했습니다.

외부 에셋에 따른 별도 라이선스 파일은 없습니다. 제작 경위를 기재한 것이며 모든 상업적 사용의 권리 문제가 없다는 법적 보장이나 제조사 승인·인증을 뜻하지 않습니다. 서비스의 사용 맥락과 다른 자료에 대한 검토는 별도입니다.
