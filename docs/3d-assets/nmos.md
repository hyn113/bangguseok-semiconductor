# NMOS 학습용 GLB 3종

## 구성
1. `nmos_01_structure.glb`: 게이트·절연막의 분리/재조립. 구조 관찰.
2. `nmos_02_channel_flow.glb`: VGS와 VDS 조건에 따른 채널·방향 표식.
3. `nmos_03_width_length.glb`: W(폭) 확대와 L(길이) 단축 비교.

모두 색·금속성·거칠기 재질, 단일 장면과 약 3.97초 애니메이션을 포함합니다. 카메라·조명·스튜디오 바닥은 제외했습니다. 모델을 웹에서 불러올 때 조명과 환경광을 설정해야 합니다. 장면의 바닥 설명판은 포함되어 있습니다.

## 상태 예시 타임라인
- 구조: 0초 조립 → 약1.97초 게이트/절연막 분리 → 약3.97초 재조립.
- 흐름: 0초 낮은 VGS로 OFF → 약1.13초 채널 형성, VDS=0이어서 흐름 표시 없음 → 약2.13초 VDS>0 조건의 방향 표시.
- W/L: 0초 기본 → 약1.3초 W 1.2배 예시 → 약2.63초 L 0.7배 예시 → 약3.97초 기본. 이는 실제 소자가 늘어나는 과정이 아니라 다른 설계 치수를 비교하는 표시입니다.
- 파란 표식은 전자 S→D, 주황은 관례적 전류 D→S. 표식은 등장/소멸 상태이지 입자 운동의 물리 계산이 아닙니다.

## 향후 클릭·슬라이더 연결
GLB만으로 사용자 조작이 자동 생기지 않습니다. 웹 개발자가 레이캐스팅/상태 관리와 UI를 추가해야 합니다.
- `manifest.json`의 `role_to_node`는 부품 역할과 실제 노드 이름을 연결합니다. glTF extras에도 `role`을 포함했으므로 Three.js의 `userData.role`로 구분할 수 있습니다.
- Blender와 glTF의 축이 다릅니다. **이 GLB에서 L은 X방향, W는 Z방향, 높이는 Y방향**입니다.
- 채널 역할 `channel`, OFF시 기판 표면은 `surface_cap_off`입니다. 웹에서 채널을 보이게 할 때 OFF 표면은 숨기고 반대로 설정합니다.
- 전압 규칙은 교육용 모델에 맞춰 별도로 구현하세요. VGS에 따라 채널, VDS 조건에 따라 방향 표시를 갱신합니다. 게이트와 실리콘 사이를 도통 경로로 연결하지 않습니다.
- W 변경 시 기판·소스/드레인·접점·게이트·절연막의 폭과 치수 화살표를 같이 갱신합니다.
- L 변경 시 중앙 영역 길이, 소스/드레인과 접점 위치, 전체 기판 및 L 화살표를 같이 갱신합니다.
- 예시 애니메이션과 실시간 조작이 같은 속성을 동시에 쓰지 않도록, 슬라이더 모드에서 AnimationMixer 액션을 정지하세요.

## 검증과 한계
- Three.js GLTFLoader 파싱, 단일 장면, 필수 부품·유효 좌표·재질 검사 통과.
- AnimationMixer로 게이트 분리, 채널/흐름 조건, 방향, W/L·소스 위치 변화 확인.
- 채널/흐름 및 W 확대 GLB를 Blender로 재수입하여 렌더 확인.
- 실제 Mac/Safari/모바일 GPU·성능은 미검증이며 모바일 최적화/압축을 적용하지 않았습니다.
- 평면형 nMOS 개념 모델입니다. 색/비율/두께는 교육용 과장입니다. 실사 칩 사진, 제조사 CAD, 전기장·반도체 물리 시뮬레이터가 아닙니다.
- 누설전류·공핍층·포화/핀치오프·단채널 효과는 구현하지 않았습니다. W/L 경향은 같은 바이어스와 장채널 가정을 전제로 합니다.
- 사용자가 제공한 그림은 원리 이해에만 참고했으며 외부 3D·사진·텍스처는 포함하지 않았습니다. 상업 사용의 법적 무침해 보장을 뜻하지 않습니다.
